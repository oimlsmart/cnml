# For Developers

CNML is open source. The whole stack lives in two repos:

- [`oiml-cs-certificates/`](https://github.com/oimlsmart/oiml-cs-certificates) — Ruby project: cert schemas + 880 sample certs + normalizer
- [`digital-certificates/`](https://github.com/oimlsmart/digital-certificates) — CNML web app + packages + PKI server

## Contributing

1. **Schema changes** — start in the Ruby project. Validate with `ruby scripts/validate_certs.rb`. Sync YAMLs to `packages/cnml-schemas/src/schemas/`. Run `pnpm gen:schemas` to regenerate the schema index.
2. **Web app changes** — work in `apps/cnml-web/`. Use `pnpm dev`. Run `pnpm test` + `pnpm test:e2e` before committing.
3. **PKI server changes** — work in `oiml-pki-server/`. Run `bundle exec rspec`. Never use `require_relative` inside `lib/` — autoload only.
4. **Docs** — `src/content/docs/*.md`. Rendered by the `/docs` route.

## Code quality rules

- **No bespoke forms.** The schema IS the spec. If SchemaForm can't render a field, the schema is incomplete — fix the schema.
- **No `require_relative` inside `lib/oiml_pki/`.** Use autoload (defined in `lib/oiml_pki.rb`).
- **No `send` to call private methods.** No `instance_variable_set/get`. No `respond_to?`.
- **No `double()` in specs.** Use real instances.
- **Open/closed.** Adding a new check, key backend, or schema = new file + one registration line. No edits to existing modules.

## Build & test

```bash
# Ruby project (canonical schemas)
cd oiml-cs-certificates
bundle install
ruby scripts/validate_certs.rb      # 880 certs, 0 errors expected

# Web app + packages
cd ../digital-certificates
pnpm install
pnpm gen:schemas                    # regenerate schema index from YAMLs
pnpm gen:types                      # regenerate TS types from schemas
pnpm dev                            # http://localhost:4321
pnpm build                          # production build to dist/
ANALYZE=1 pnpm build                # + bundle stats.html

# PKI server
cd oiml-pki-server
bundle install
ruby app.rb                         # http://localhost:4455
bundle exec rspec                   # 49 specs

# Tests
cd ..
pnpm test                           # 46 TS unit tests
pnpm test:e2e                       # 52 Playwright tests
pnpm smoke                          # quick sign+verify via Node
```
